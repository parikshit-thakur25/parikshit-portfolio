## 🔥 Features & Architecture

- **✍️ Cursive Handwriting Intro Splash Screen:** An animated handwriting introduction (`"hello ,"` ➔ `"parikshit"`) with keyboard and click-to-skip functionality.
- **💻 Cyber Terminal Widget (`parikshit@local:~$`):** An interactive command-line simulator supporting commands such as `whoami`, `status`, `skills`, `projects`, `contact`, and `clear`.
- **🫀 CardioVision AI Featured Project:** Showcases my clinical heart disease risk assessment project built with Python, Scikit-Learn, and Flask.
- **📄 Client-Side PDF Resume Manager:** Supports resume file selection, viewing, and deletion using the HTML5 `FileReader` API and browser `localStorage`.
- **🎨 Deep Space & Crimson Red Glassmorphism:** A custom visual design featuring dark backgrounds, ambient lighting effects, glassmorphism, and high-contrast interface elements.
- **📱 Responsive Interface:** Designed to provide a usable browsing experience across different screen sizes.
- **⚡ Lightweight Frontend:** Built with vanilla HTML, CSS, and JavaScript to keep the application simple and easy to maintain.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Git
- Python 3
- A modern web browser

### Option 1: Clone the Repository

```bash
git clone https://github.com/parikshit-thakur25/parikshit-portfolio.git
cd parikshit-portfolio
```

### Option 2: Run the Local Development Server

From the project directory, execute:

```bash
python3 -m http.server 8000
```

Open your browser and visit:

```text
http://localhost:8000
```

To stop the server, press `Ctrl + C` in your terminal.
